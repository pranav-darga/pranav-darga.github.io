# CLAUDE.md

## Design Context

This project is set up for the Impeccable design skill. Before making any visual or UX change, read:

- **PRODUCT.md** — register (`brand`), audience (recruiters/hiring managers), positioning ("the site itself is the proof"), and strategic principles.
- **DESIGN.md** — the visual token system: colors, typography, elevation, and component specs, named around the "Working Proof" north star.

Run `/impeccable` for the full command menu, or `/impeccable live` to iterate on elements directly in the browser (already configured for this project).
